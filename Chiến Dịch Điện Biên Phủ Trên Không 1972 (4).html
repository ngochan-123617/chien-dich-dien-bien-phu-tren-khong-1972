VŨ KHÍ CHIẾN ĐẤU: BẤT PHƯƠNG TRÌNH BẬC NHẤT MỘT ẨN

Trang bị kiến thức từ Bài 6 (SGK Toán 8)

1. Khái niệm & Nghiệm:

• Bất phương trình dạng ax + b < 0 (hoặc ax + b > 0; ax + b ≤ 0; ax + b ≥ 0) trong đó a, b là hai số đã cho, a ≠ 0 được gọi là bất phương trình bậc nhất một ẩn x.

• Số x₀ là một nghiệm của BPT A(x) < B(x) nếu A(x₀) < B(x₀) là khẳng định đúng.

2. Cách giải BPT bậc nhất một ẩn:

Xét ax + b < 0 (a ≠ 0) ⇔ ax < -b:

  • Nếu a > 0 thì x < -b/a (Giữ nguyên chiều).
  • Nếu a < 0 thì x > -b/a (Đổi chiều BPT).

* Các BPT ax + b > 0, ax + b ≤ 0, ax + b ≥ 0 giải tương tự.

✔ Trả lời đúng 1 câu: +1 Điểm lực và được quyền khai hỏa bắn máy bay địch.

⏱ Gồm 3 Giai đoạn (9 câu hỏi độ khó tăng dần). Tổng thời gian toàn chiến dịch là 5 phút.
